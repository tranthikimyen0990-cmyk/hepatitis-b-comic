# Hepatitis B: The Silent Story Inside Your Liver

Interactive 50-page digital science comic by Tran Thi Kim Yen.

## GitHub Pages

This project is a self-hosted HTML flipbook designed to run directly from the repository root.

- `index.html` is the reader (already uploaded).
- `pages/001.webp` through `pages/050.webp` are the 50 comic images (upload required).
- `.nojekyll` allows the directory to be served without Jekyll processing.

### Publish

1. Extract `Hepatitis_B_GitHub_Pages_Ready.zip` from your prepared files.
2. In this GitHub repository choose **Add file → Upload files**.
3. Upload the **50 WebP files** into a directory named `pages` (file paths must be `pages/001.webp` to `pages/050.webp`).
4. Commit files to `main`.
5. Under **Settings → Pages**, set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** and save.
6. Open the site at https://tranthikimyen0990-cmyk.github.io/hepatitis-b-comic/

Check pages 1, 20, 30, 40 and 50 on desktop and mobile. Keep academic sources, image rights and health information reviewed before public distribution.
